# AvtoVIP — ekran görüntülərindəki marka yoxlaması (2026-11-15)

Avtomobil kataloqunda birləşdirildi: Hindustan → Hindustan Motors; Iso → Iso Rivolta; Leyland Cars → Leyland; Lynk And Co → Lynk & Co; Moskvitch → Moskvich; Willys Overland → Willys. Bütün CSV model sətirləri kanonik markaya köçürüldü, eyni model adları təkrarlanmadı.

Hava nəqliyyatında Gulfstream Aerospace modelləri Gulfstream altında toplandı. Gulfstream American (GA-7 Cougar) tarixi ayrıca istehsalçı olduğu üçün saxlanıldı. Airbus Helicopters, Airbus Corporate Jets, de Havilland və de Havilland Canada avtomatik birləşdirilmədi: bunlar ayrıca bölmə və ya tarixi istehsalçı ola bilər.

Loqoların şəkil faylları və orijinal rəngləri dəyişdirilmədi. Qaranlıq temada tünd loqoların kontrast problemi ayrıca dizayn yoxlaması tələb edir.
